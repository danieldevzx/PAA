# PAA (Projetgo de Analise de Algoritmos)

## Objetivo
Esse repositorio tem como objetivo o estudo de algoritmos e estruturas de dados usando como base o livro do professor e opesquo ziviani, tendo em vista não so a replica de exemplos trazendo minha leitura sobre, mas também as soluções de alguns exercícios em conjunto com outros exercícios de maratona.
